# Changelog

## [0.3.1] - 2026-08-18

- Validate flag types and harden command-tree mutations.
- Make project scaffolding updates deterministic and rollback-safe.
- Improve terminal and progress validation, runtime error boundaries, and CI reproducibility.

## [0.3.0] - 2026-08-18

- Hardened project and command scaffolding against invalid names and path traversal.
- Fixed mutable command-tree flag parsing and inherited flag collisions.
- Added injectable command streams, typed-package metadata, safer completion output,
  and improved terminal wrapping.

## [0.2.0] - 2026-08-16

- Added project management commands for initializing projects and adding commands.
- Improved CLI output, caching, and Korean text alignment.
- Published runtime dependencies as `wpyconf` and `wpylog`.

## [0.1.0]

- Initial public CLI toolkit release.
